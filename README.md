# Lytic

A modern, high-performance SaaS analytics and financial dashboard built with Next.js 15, Tailwind CSS, and React 19.

## Features

- **Executive Analytics Dashboard**: Real-time ARR, MRR, user growth, and churn rate metrics.
- **Interactive Revenue Charts**: SVG area charts comparing actual revenue against forecasted targets.
- **Traffic Acquisition Breakdown**: Donut chart tracking Direct, Organic, Social, and Paid marketing channels.
- **Campaigns ROI Table**: Performance and conversion metrics for active acquisition campaigns.
- **Authentication Suite**:
  - Magic Code (OTP) authentication with animated digit inputs.
  - Password login & registration.
  - Password reset with real-time feedback.
  - Dark glassmorphic theme with WebGL grain shader background.

## Getting Started

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) in your browser.
